01 / 产品定义

云枢 · AWS + 阿里云运维聚合平台

把分散在两家云、多个账号、多个地域的资源和监控，收拢到一个只读、统一的视图里。

版本v0.1 · MVP
日期2026-09-28

背景

团队同时在用 AWS 和阿里云，资源散落在多个账号和地域。排查问题要在两个控制台之间来回切换，也没有一份统一的资源台账和监控视图。

产品目标

01
一处看全多云、多账号、多地域的资源统一成一份台账
02
快速定位按名称、ID、IP、标签跨云搜索；监控曲线可以跨云对比
03
安全接入只需要只读 AK，密钥加密存储，关键操作可审计

设计原则

只读优先 统一语言：状态、指标、单位归一 可追溯：每次同步和变更都有记录

用户与角色

管理员admin
运维负责人 / SRE：纳管云账号、触发同步、管理用户、查看审计日志
只读用户viewer
研发、值班同学：查看概览、资源清单和监控，不能修改任何配置

MVP 功能范围

  • 多账号接入：AK/SK，可选 AssumeRole / RAM 角色，支持 AWS 中国区
  • 统一资源清单：云主机、数据库、负载均衡、对象存储
  • 定时 + 手动同步，保留同步历史和错误明细
  • 监控趋势图，支持多个资源跨云对比
  • 概览：资源分布、CPU Top10、闲置主机、到期提醒
  • 多用户与角色，关键操作写入审计日志

暂不包含（后续迭代）

  • 实例启停与审批
  • 费用账单聚合（Cost Explorer / 费用中心）
  • 告警与通知（钉钉 / 飞书 / 企业微信）
  • 更多资源类型（云盘、EIP、Redis、VPC）
